Getting Started with EDS

This section helps authors and administrators understand how to setup and configure EDS for publishing content from AEM Guides to CDN via GIT pipeline.
Adobe Experience Manager Guides allows you to publish your DITA content directly to Edge Delivery Services (EDS) through a dedicated GitHub-based publish profile. This capability enables organizations to deliver high-performance, responsive documentation experiences while maintaining DITA-based authoring workflows in Experience Manager Guides.
A user with administrative privileges can setup and configure the Edge Delivery Services for AEM Guides content. You can use Adobe provided CDN or BYO CDN.
Following are the steps to setup and configure publishing to EDS:
  1. Setup GIT repository
  2. Generate OAuth Credentials and setup Callback URLs
  3. Configure AEM Code Sync app
  4. Configure AEM Sites Admin profile
  5. Configure Publish Profile for EDS in AEM Guides

Setup GIT repository

Setting up a GIT repository is the first step towards the workflow. You can use the Adobe provided Boilerplate template to clone/configure your GIT repository. The template consists of all the dependencies, blocks, and configurations required to publish structured DITA content from AEM Guides to EDS.
Following are the steps to setup GIT repo:
  1. Create your GitHub account using Adobe ID.
  2. Login to your GIT account
  3. Clone the boilerplate template to create new repository
  4. Provide a name to your GIT repo. Ensure that the name is relevant as it will be configured at multiple places throughout the workflow.
  5. Create new OAuth credentials for your repository and generate Client ID and Client Secret Key.
  6. Setup Callback URL in your OAuth settings.
  7. Copy/Store these Client ID and Secret Key as it will be used for configuring your AEM instance while setting up EDS profile.
  8. Download and install AEM Code Sync app in your GIT repo.
  9. Setup Mount path in your GIT repo.
  10. Your GIT repo is configured.
