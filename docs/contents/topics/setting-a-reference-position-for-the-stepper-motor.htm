PREREQUISITE The gantry robot is fully set up and operational.
The linear bearing is equipped with a limit switch. The following procedure for setting a reference position ensures reproducible positioning for stepper motor.
  1. Drive the stepper motor counter-clockwise until the limit switch 3B1 is activated.
  2. Once the limit switch is activated, stop the stepper motor.
  3. Drive the stepper motor clockwise one step at a time until the limit switch is released.
  4. Once the limit switch is deactivated, set the reference position.
