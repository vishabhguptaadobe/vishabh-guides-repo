MacOS

To install GUI Guider on MacOS, perform the following steps.:
  1. Install SDL2:
    • Download SDL source code:wget https://github.com/libsdl-org/SDL/releases/download/release-2.26.5/SDL2-2.26.5.tar.gz

      tar -zvxf SDL2-2.26.5.tar.gz

      cd SDL2-2.26.5

      ./configure --prefix=/usr/local

      sudo make -j && sudo make install







  2. Run brew install cmake command.
  3. Install the MCUXpresso IDE.
    Note: M core chip: ensure that the SDL2 is installed in /usr/local.
  4. Install GUI Guider on MacOS.
    1. Download the installer from www.nxp.com.
    2. Click the installer package and complete the installation based on the installation guide.
