Brand: SuperRobot
The gantry robot EPGR-S is intended to automate the movement of small, light-weight, inanimate objects. The objects are picked up by a gripper, lifted up by a piston rod cylinder, and moved linearly to the new location by a stepper. The gantry robot can change the orientation of the object using an RC servo. The gantry robot is equipped with sensors that sense the position of the cylinder and the gripper. The linear bearing is equipped with an end-position switch for referencing the stepper motor.
The gantry robot is intended to be part of a larger machine. The robot provides electrical, pneumatic, and mechanical interfaces for being properly integrated.
The piston rod cylinder, the gripper, and the load circuit of the gantry robot use compressed oiled air. The stepper motor, the RC servo, and the control circuit operate with extra-low voltage.
The gantry robot is intended for use in industrial applications. It is not intended to be used at home, in medical applications, or for food processing. The gantry robot is not suitable for use in explosive atmospheres.
The gantry robot may only be erected, commissioned, operated, maintained, and disassembled by personnel qualified for the task. Reading the documentation is part of the intended use.
